# GameICU.Tools — WukongMP 联机增强工具

> 独立第三方 mod，叠加在官方 **WukongMp Co-op** 之上。官方 Coop 保持原版不动，
> 增强功能全部由本 mod 提供，官方更新可直接替换，互不冲突。

- **版本**：v1.0（第一版）
- **作者**：GameICU
- **依赖**：WukongMp.Sdk ≥ 0.3.1（官方 Coop 自带）

---

## 一、功能一览

| 命令 | 功能 | 适用场景 |
|---|---|---|
| `force_cg` | 强制跳过"等待其他玩家到达"阶段，直接播放过场动画，并把所有玩家传送到执行者（房主）位置 | 队友掉线/挂机导致过场卡住时 |
| `test_wait` | 单人模拟"多人等待过场"状态（测试用） | 单人测试 force_cg 完整链路 |
| `tpall` | 把服务器上所有玩家瞬间传送到执行者（房主）所在位置 | 队友迷路、掉队、集合 |
| `cglist` | 查询全员等待过场 ID（6 种子查询） | 查看哪些过场已经历/未经历 |

> 本版本不包含击杀同步与区域怪物重扫，怪物行为与官方 Coop 完全一致。

## 二、使用方法

游戏内按 **F1** 打开控制台，输入命令后回车（支持 TAB 补全）。

### 1. force_cg — 强制过场

```
force_cg            自动取本地待播放的过场 ID
force_cg 80005020   手动指定过场 ID
```

- 无参执行时，自动读取你当前排队中的过场（走到过场触发点后游戏会自动排队）。
- 执行后：服务器把该过场标记为"已开始" → 所有客户端的等待闸门打开 → 全员
  直接播放过场，同时全员被传送到执行者位置。
- 屏幕中央会显示大提示确认。

**典型用法（队友卡在"等待其他玩家"界面时）：**
1. 房主（或任意玩家）走到过场触发点，确认自己能看到过场排队。
2. 控制台输入 `force_cg`，全员立刻进入过场。

### 2. test_wait — 单人模拟多人等待

```
test_wait <过场ID>   把指定过场塞入播放队列并开启模拟
test_wait            仅开启模拟（已走到真实触发点、已有排队过场时用）
test_wait -1         关闭模拟
```

开启后单人也会像多人一样卡在"等待其他玩家"界面，此时执行 `force_cg` 即可放行。
用于验证/演示完整链路，测完记得 `test_wait -1` 关闭。

### 3. tpall — 全员传送到房主

```
tpall
```

- 以执行者当前的位置/朝向为准，服务器上所有玩家（含执行者自己）瞬间传送过去。
- 跨区域同样生效（使用 GlobalAll 中继）。

### 4. cglist — 查询全员等待过场 ID

```
cglist               所有已知的全员等待 ID
cglist area          当前区域所有
cglist done          所有已经历（本会话已开始/已完成）
cglist undone        所有未经历
cglist area done     当前区域已经历
cglist area undone   当前区域未经历
```

- 数据来源：服务器聚合所有区域的过场状态 + 本地播放队列 + 运行时探测的播放历史。
- 若游戏没有暴露完整过场配置表，"全集"会退化为"本会话已观测集合"并在结果中注明。

## 三、服务器端安装

1. 把 `mods/GameICU.Tools/` 目录（含 `GameICU.Tools.dll`、`GameICU.Tools.Common.dll`、`manifest.json`）放入服务器 mods 目录。
2. 把 `server_mods/` 下的 `GameICU.Tools.Common.dll`、`GameICU.Tools.Serverside.dll` 放入服务器 server_mods 目录。
3. 重启服务器，日志中应出现：
   - `Assigned server RPC offset ... to contract set GameICU.Tools.Common`
   - `Loaded mod: GameICU Tools`
4. 玩家进入服务器时，启动器会自动同步客户端侧 mod 文件，无需手动安装。

---

## 四、注意事项

- 命令由执行者本人输入即可，无需所有人操作。
- `force_cg` 传送的是"执行者位置"——想让全员传到哪，就让谁执行。
- 本 mod 只含 DLL，**不要** Steam 验证游戏完整性（会清掉启动器相关文件）。
- 若命令无反应，先确认启动器是否已同步最新版（旧缓存会导致命令不注册）。
- 传送/过场为即时生效；网络较差的玩家（跨境）可能偶发掉线重连，属 QoS 问题，建议加速器香港节点。
